# ESP8266 Universal Controller

Универсальный контроллер на базе **NodeMCU (ESP8266)** для управления реле, кнопками и датчиками температуры (DS18B20) по гибким правилам.

## Возможности

- **Каналы** — настройка пинов как реле, кнопок или датчиков
- **Правила** — привязка событий (кнопка, датчик, реле) к исполнителям (реле) с гистерезисом
- **Веб-интерфейс** — встроенная HTML-панель с вкладками: Каналы, Правила, Wi-Fi, HTTP
- **Inline-редактирование** — названия каналов и правил редактируются прямо в таблице
- **Текущее состояние** — отображение статуса реле, кнопок и датчиков в реальном времени
- **HTTP-интеграция** — отправка POST-запросов на внешний сервер при изменении состояний
- **Wi-Fi Config Portal** — автоматический режим точки доступа для первой настройки сети

## Стек

- **Плата:** NodeMCU v2 (ESP8266)
- **Фреймворк:** Arduino (PlatformIO)
- **Датчики:** DS18B20 (OneWire, DallasTemperature)
- **JSON:** ArduinoJson 6
- **Файловая система:** LittleFS

## Быстрый старт

```bash
# Клонировать
git clone https://github.com/sperevoznuk/esp8266-universal.git
cd esp8266-universal

# Собрать и залить
pio run --target upload

# Монитор порта
pio device monitor
```

При первой загрузке ESP8266 создаёт точку доступа `ESP8266-Setup-XXXX`. Подключитесь к ней, перейдите по адресу **192.168.4.1**, укажите имя и пароль вашей Wi-Fi сети — устройство перезагрузится и подключится к роутеру.

## Конфигурация

Файл `platformio.ini` — основные настройки:

- Плата: `nodemcuv2`
- Flash: 4 MB
- Скорость: 115200 бод
- Порт: `/dev/ttyUSB0` (Linux)

## Управление

После подключения к Wi-Fi устройство доступно по присвоенному IP-адресу. Веб-интерфейс позволяет:

- Добавлять/удалять каналы (реле, кнопки, датчики)
- Создавать правила автоматизации
- Настраивать Wi-Fi без перепрошивки
- Просматривать пример JSON-полезной нагрузки для HTTP-сервера
